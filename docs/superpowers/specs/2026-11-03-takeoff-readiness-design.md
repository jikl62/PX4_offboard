## 行为修复

- 起飞平台默认统一为向上相对本次地面基准 1.5 m；仅修改相关默认与演示，保留所有同值阈值。相对高度 `h=z0-z_NED`，向上速度 `-vz_NED`。地面基准只在新任务安全准入时建立，重复任务不得重建。
- 离地证据独立于控制计算：新鲜有效位置/速度、落地检测、至少两个独立源样本、原持续时间/高度/运动阈值、估计器无重置/跳变。按有界异步汇合接纳消息；通用着陆/停桨证据不放宽。共同估计漂移仍不能由这些内部反馈排除，物理离地仍需飞手/录像或独立测距。
- 导航只能在离地证据和目标高度稳定后授权；状态分别暴露请求、解锁、爬升、离地待确认、估计离地已确认、到高及导航许可。矛盾状态不作为接地停桨证据。
- 正常结束及明确可恢复 RC 准备失败，在新鲜安全地面、实际模式退出、杆位复位、输出停止、无待决事务后进程内重建任务 Core。保留 Runtime 命令历史与 ACK 隔离；通用/发布/时钟/估计器严重故障不能自动清除。减少串联地面窗口，仍保留预发送与新授权证据。
- 环境校验核对实际私有控制器，避免 SDK 目录中不使用的旧二进制成为导航启动条件。
